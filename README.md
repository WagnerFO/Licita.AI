# Licita.AI

Sistema web para gerenciamento de contratos e processos
licitatórios da Prefeitura Municipal de Vitória de Santo Antão.

## Tecnologias

Frontend
- Angular
- TypeScript

Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Maven

Banco de Dados
- PostgreSQL
- Flyway

DevOps
- Docker
- GitHub Actions

## Estrutura

/backend
/frontend
/docs

## Pré-requisitos

- Java 21
- Node.js
- Angular CLI
- Docker
- Git

## Como executar

1. Clonar repositório
2. Iniciar PostgreSQL
3. Executar backend
4. Executar frontend

## Sprint 1

- Login e autenticação
- Cadastro de contrato
- Consulta de contratos
